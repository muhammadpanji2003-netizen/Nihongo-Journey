# Nihongo Journey

Web belajar bahasa Jepang mandiri dari Hiragana/Katakana sampai jalur latihan JLPT N5, N4, dan N3.

## Fitur
- Hiragana & Katakana dasar
- Kosakata N5, N4, N3
- Kanji N5, N4, N3
- Pola grammar N5, N4, N3
- Quiz Kana, kosakata, kanji, grammar, campuran, dan review salah
- XP, mastery, akurasi, streak, progress per level
- Progress tersimpan di browser dengan localStorage
- Responsive desktop & mobile
- Halaman profil penyusun: Muhamad Panji, S.Pd.

## Deploy ke GitHub + Vercel
1. Extract ZIP.
2. Upload seluruh isi folder ke repository GitHub.
3. Di Vercel pilih **Add New > Project**.
4. Import repository GitHub.
5. Framework Preset: **Other**.
6. Build Command: kosongkan.
7. Output Directory: kosongkan.
8. Klik **Deploy**.

## Catatan materi
JLPT tidak menerbitkan daftar resmi kosakata/kanji per level. Dataset dalam project ini adalah kumpulan latihan pembelajaran yang disusun per tingkat, bukan daftar resmi JLPT.
